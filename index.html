XSgrep

Extra Small ~200 LoC x86-64 Assembly text-search utility with a naive substring-search algorithm.

Demonstrates low-level design, manual byte-level data management, and register manipulation. Features:

  • Parses command-line arguments.
  • Open and reads specified files.
  • Uses an algorithmic loop to find all matching lines, checking file in chunks of 4096 bytes against specified keyword.
  • Prints every line and line number matching with user keyword.
  • Built as an exercise in understanding Linux system calls, x86-64 registers, memory buffers, and low-level file processing.
